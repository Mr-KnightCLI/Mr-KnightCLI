# Behind the mask

I'm Harsh, the Java developer behind **Mr-KnightCLI**. I build backend services and like tracing what happens after a request arrives, from the first byte on a socket to the last write on disk.

[Case files](#case-files) · [Merged contributions](#merged-contributions) · [The armory](#the-armory)

## Case files

| Project | Inside the build |
| --- | --- |
| [JRedis](https://github.com/Mr-KnightCLI/jredis) | A Java 21 key-value server. It parses RESP2 over TCP, expires keys, handles concurrent clients, and can recover writes from an append-only log. |
| [Cove](https://github.com/Mr-KnightCLI/cove-clipboard) | A cross-device clipboard. Spring Boot pushes text updates over WebSockets and expires stored notes after 24 hours. |
| [ApplyFlow](https://github.com/Mr-KnightCLI/ApplyFlow) | A job-application tracker with a stage board, filters, and follow-up reminders backed by Spring Data JPA and H2. |
| [TabTamer](https://github.com/Mr-KnightCLI/tabtamer) | A searchable bookmark library with tags, collections, and a Chrome/Edge extension for saving the current tab. |
